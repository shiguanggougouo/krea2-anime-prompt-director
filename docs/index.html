Why

通用提示词助手，和这个 skill 的差别

Krea 2 要的是连贯的自然语言描述，不是 Danbooru 标签串。差别主要在这五处。

通用写法

  • 前置 masterpiece, best quality, 8k 之类质量宏
  • 背景只写"在房间里""在户外"
  • 写"天下第一武道会"，指望模型自己知道长什么样
  • 同一个角色永远套同一套默认服装
  • 反复出图都是同一个姿势同一个场景

本 skill

  • 连贯英文散文，标签只在你要的时候才给
  • 选一个原作经典场景，描述建筑、材质、尺度、光照、天气
  • 把专有名词翻译成可绘制的物理布局与可辨识标识
  • 先判定"故事时刻版本"：篇章、地点、身份、变身状态
  • 同一角色再次出现时，场景和动作都换
Capabilities

六件它特别较真的事

🎭

身份靠可见证据

发型与发色、眉眼与标记、体型轮廓、招牌服装的层次/颜色/材质、配件道具。按取景挑选 4–7 个最有辨识度的线索，而不是"动漫忍者装"。

🏛️

场景要重建，不要命名

"天下第一武道会"→ 浅色方石高台擂台、脚下红色界线、环绕的阶梯观众席、红漆立柱、赛事旗帜、瓦顶入口楼阁。

🌄

环境没给就自动补

只给角色名、或只给动作/风格/情绪而没给地点时，从该角色的动漫、漫画或游戏原作里挑一个有戏的经典舞台，再把实景写出来。

🔁

重复请求自动区分

对话内记录每个角色用过的场景与动作。再次请求时换一个原作场景和一个动作，不重复同一套地标排布或招牌桥段。

🎨

单一主导画风

吉卜力 / 新海诚 / 京阿尼 / Madhouse 都市黑色 / 90 年代机战赛璐璐 / 少女 / 青年 / 经典热血战斗 —— 一个锚点，最多一个有界变体。

🧾

检索诚实

没真正查到 Krea2 Character Catalog 条目就绝不说"我查过目录"。条目只当证据，不当设定，更不等于"该角色在训练数据里"。

Workflow

它内部怎么走

除真正的必要歧义外，它默认自行推断并直接出文，不反问。

  1. 分类意图

    角色＋原作世界（未指定环境）／角色＋指定环境／动作战斗／纯背景／原创角色／风格探索。保留你给的任何画幅、机位、动作、服装、时代或情绪。

  2. 解析"故事时刻版本"

    先决定你要的是哪个篇章、地点、身份、变身状态或时期的形态 —— 头发、服装、装备、年龄、伤势、状态都随之改变，不把默认设计贴到每个场景上。

  3. 自动补全未指定的环境

    没给地点就不留白：从原作挑一个有叙事意义、视觉上记得住的舞台，用至少三个场景专属标识 + 前景/中景/远景 + 统一的时间天气光照氛围把它写实。

  4. 把专有名词翻译成可绘制描述

    物理类型与布局 → 可见标识 → 空间摆位 → 材质尺度氛围 → 与这一幕剧情的关联。专有名只作为可选锚点，不代替画面描述。

  5. 选定一个视觉语言

    参考内置风格矩阵选主导锚点；画风只影响线条、配色、光照与质感，不覆盖角色的招牌设计。

  6. 按稳定顺序搭画面

    媒介与意图 → 焦点主体与身份 → 具体地点与剧情节点 → 前景 → 中景 → 背景纵深 → 光照与配色 → 渲染与情绪基调。

  7. 套用场景密度标准

    两到三个空间层次、三个以上具体场景标识、一套自洽光照、一个受控配色、一到两个大气运动、一个构图线索。

  8. 输出 POSITIVE + 中文对照

    角色入景约 150–350 词，纯背景约 120–300 词。去掉质量宏与过时的 Anima 语法；中文忠实对应英文的每一项视觉决策。

Style anchors

内置画风锚点

一个主导锚点，最多一个有界变体。名字只是视觉锚，不是魔法关键词 —— 必须配上具体的配色、线条、光、介质与情绪。

Studio Ghibli aesthetic手绘水彩感、克制的自然配色、风化的乡间木石、层叠绿意、柔和正午光
Makoto Shinkai / CoMix Wave Films高饱和天空、细密云缘、阳光耀斑、蓝调时刻渐变、电线与电线杆作前景

Install

一分钟装上

整个文件夹放进你的 agent 读取的 skills 目录即可。SKILL.md 与 references/ 必须在一起。

git clone https://github.com/<your-account>/krea2-anime-prompt-director.git .agents/skills/krea2-anime-prompt-director
git clone https://github.com/<your-account>/krea2-anime-prompt-director.git ~/.workbuddy/skills/krea2-anime-prompt-director

第一条适用于 Codex 的仓库内 .agents/skills/；第二条适用于 WorkBuddy 等用户级 skills 目录。

Honest limits

它不做什么

不自带 Krea2 Character Catalog 数据集。只有真的存在可访问条目、导出文件或你提供的文件时才使用；查不到就继续用可靠知识，不伪造引用。
目录条目是临时性的。匹配结果只是有用证据，不等于设定，更不等于"该角色在 Krea 2 训练数据里"。
不保证系列一致性。纯文本提示词无法锁死角色连续性；做系列请用 Krea 2 的风格参考，或 20–40 张参考图组成的 mood board。
默认不输出负面提示词。除非你明确要求单独给一份 negative prompt。
