能力Capabilities

八件它特别较真的事Eight things it is strict about

01

身份靠可见证据Identity through visible evidence

发型与发色、眉眼与标记、体型轮廓、招牌服装的层次/颜色/材质、配件道具。按取景挑选 4–7 个最有辨识度的线索，而不是"动漫忍者装"。Hair color and cut, eyes and markings, silhouette, signature costume layers/colors/materials, accessories. Four to seven cues chosen for the framing — never "anime ninja outfit."

02

动作要能画出"这一刻"Action you can actually draw

不写"动态姿势""战斗姿势"。要写清意图、重心与支撑、发力方向、肢体力学，以及环境里的一两个后果 —— 溅开的水、被带起的衣摆、蹬飞的碎石。只定格一个瞬间：预备、决定性接触、或跟随动作。Never "dynamic pose" or "fighting pose." It writes intention, weight and support, direction of force, body mechanics, and one or two consequences in the scene — kicked-up water, trailing cloth, scattered gravel. One instant only: anticipation, the decisive contact, or follow-through.

03

多人之间要有交流Characters actually interact

多人画面先定关系节点：谁先动手、对方怎么回应、视线在哪交汇、接触点在哪、双方身体与空间各自发生什么改变。不再是一排人各摆各的姿势。Multi-character frames start with the relationship beat: who initiates, how the other responds, where eyelines meet, where contact happens, and what changes across both bodies and the space. No more figures posing side by side.

04

场景要重建，不要命名Rebuild the place, don't name it

"天下第一武道会"→ 浅色方石高台擂台、脚下红色界线、环绕的阶梯观众席、红漆立柱、赛事旗帜、瓦顶入口楼阁。"World Martial Arts Tournament" → a raised pale-stone square ring, a red boundary line underfoot, crowded stepped stands, red-painted posts, tournament banners, a tiled-roof entrance pavilion.

05

环境没给就自动补Fills in an open environment

只给角色名、或只给动作/风格/情绪而没给地点时，从该角色的动漫、漫画或游戏原作里挑一个有戏的经典舞台，再把实景写出来。Given only a character name — or an action, style or mood with no location — it picks a story-rich classic stage from that character's anime, manga or game canon and writes the actual scenery.

06

重复请求自动区分Repeat requests stay distinct

对话内记录每个角色用过的场景与动作。再次请求时换一个原作场景和一个动作，不重复同一套地标排布或招牌桥段。It tracks the scenes and actions already used for each character. On a repeat request it changes the canon setting and the action, never reusing a landmark arrangement or signature beat.

07

单一主导画风One dominant style anchor

吉卜力 / 新海诚 / 京阿尼 / Madhouse 都市黑色 / 90 年代机战赛璐璐 / 少女 / 青年 / 经典热血战斗 —— 一个锚点，最多一个有界变体。Ghibli / Shinkai / Kyoto Animation / Madhouse urban-noir / 1990s mecha cel / shoujo / seinen / classic battle-shonen — one anchor, at most one bounded twist.

08

检索诚实Honest about lookup

没真正查到 Krea2 Character Catalog 条目就绝不说"我查过目录"。条目只当证据，不当设定，更不等于"该角色在训练数据里"。It never says "I checked the catalog" unless an entry was genuinely inspected. An entry is evidence, not canon — and never proof that the character is in the training data.

诚实边界Honest limits

它不做什么What it does not do

不自带 Krea2 Character Catalog 数据集。只有真的存在可访问条目、导出文件或你提供的文件时才使用；查不到就继续用可靠知识，不伪造引用。 It does not bundle the Krea2 Character Catalog dataset. It uses an accessible entry, export or provided file when one exists, and otherwise continues with reliable knowledge instead of fabricating a citation.
目录条目是临时性的。匹配结果只是有用证据，不等于设定，更不等于"该角色在 Krea 2 训练数据里"。 Catalog entries are provisional. A match is useful evidence, not canon, and never proof that the character exists in Krea 2's training data.
不保证系列一致性。纯文本提示词无法锁死角色连续性；做系列请用 Krea 2 的风格参考，或 20–40 张参考图组成的 mood board。 Series consistency is not guaranteed. Prompt text alone cannot lock character continuity; use a Krea 2 style reference or a mood board of roughly 20–40 frames.
默认不输出负面提示词。除非你明确要求单独给一份 negative prompt。 No negative prompt by default. Only when you explicitly ask for a separate negative prompt.
工作流Workflow

它内部怎么走How it works internally

除真正的必要歧义外，它默认自行推断并直接出文，不反问。Unless an essential ambiguity blocks a coherent result, it infers sensible defaults and writes the prompt instead of asking.

  1. 分类意图Classify the intent

    角色＋原作世界（未指定环境）／角色＋指定环境／动作战斗／纯背景／原创角色／风格探索。保留你给的任何画幅、机位、动作、服装、时代或情绪。Character + canon world (no environment) / character + specified environment / action or combat / background only / original character / style exploration. Any aspect ratio, camera angle, action, costume, period or mood you gave is preserved.

  2. 解析"故事时刻版本"Resolve the story-moment version

    先决定你要的是哪个篇章、地点、身份、变身状态或时期的形态 —— 头发、服装、装备、年龄、伤势、状态都随之改变，不把默认设计贴到每个场景上。Decide which arc, location, role, transformation state or time period you want. Hair, costume, equipment, age, injuries and condition all follow — one default design is never pasted onto every scene.

  3. 设计动作与互动Design the action and the exchange

    为这一刻写一个可画的动作：意图、重心与支撑、发力方向、肢体力学，并让环境在接触点给出反应。多人则先定关系节点 —— 谁先动手、谁回应、视线与接触点落在哪里。只定格一个瞬间：预备、决定性接触、或跟随动作。Write a drawable action for this beat: intention, weight and support, direction of force, body mechanics, plus a reaction at the contact point in the environment. With several characters, decide the exchange first — who initiates, who responds, where eyelines and contact land. One instant only: anticipation, the decisive contact, or follow-through.

  4. 自动补全未指定的环境Fill in an unspecified environment

    没给地点就不留白：从原作挑一个有叙事意义、视觉上记得住的舞台，用至少三个场景专属标识 + 前景/中景/远景 + 统一的时间天气光照氛围把它写实。No location means no blank background: pick a narratively meaningful, visually memorable canon stage and ground it with at least three scene-specific identifiers, foreground/middle/distance planes, and one coherent time, weather, light and atmosphere.

  5. 把专有名词翻译成可绘制描述Translate names into drawable descriptions

    物理类型与布局 → 可见标识 → 空间摆位 → 材质尺度氛围 → 与这一幕剧情的关联。专有名只作为可选锚点，不代替画面描述。Physical type and layout → visible identifiers → placement in space → materials, scale, atmosphere → the tie to this story beat. The proper name is only an optional anchor, never a substitute for the description.

  6. 选定一个视觉语言Choose one visual language

    参考内置风格矩阵选主导锚点；画风只影响线条、配色、光照与质感，不覆盖角色的招牌设计。Pick a dominant anchor from the built-in style matrix; style shapes linework, palette, light and texture but never overwrites the character's signature design.

  7. 按稳定顺序搭画面Build the frame in a stable order

    媒介与意图 → 焦点主体与身份 → 具体地点与剧情节点 → 前景 → 中景 → 背景纵深 → 光照与配色 → 渲染与情绪基调。Medium and intent → focal subject and identity → specific place and story beat → foreground → middle ground → background depth → lighting and palette → rendering and emotional register.

  8. 套用场景密度标准Apply the scene-density standard

    两到三个空间层次、三个以上具体场景标识、一套自洽光照、一个受控配色、一到两个大气运动、一个构图线索。Two or three spatial planes, three or more concrete scene identifiers, one coherent light setup, one controlled palette, one or two atmospheric movements, one composition cue.

  9. 输出 POSITIVE + 中文对照Output POSITIVE + Chinese translation

    角色入景约 150–350 词，纯背景约 120–300 词。去掉质量宏与过时的 Anima 语法；中文忠实对应英文的每一项视觉决策。About 150–350 words for a character-in-scene prompt, 120–300 for background-only. Quality macros and obsolete Anima syntax removed; the Chinese mirrors every visual decision in the English.
